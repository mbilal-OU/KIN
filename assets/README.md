# KIN — approved brand artwork

The founder-approved **exact** brand logo was uploaded as `logo.png` in the KIN project conversation. It consists of:

- Metallic gold interwoven ribbon symbol, on black
- Gold `KIN` wordmark with a visible **dot over the I**
- White “Kinetic Intelligence Network” underneath
- Tagline: **“Life changes. KIN moves with you.”**

## Install the original image

1. Download [the exact PNG from the project chat](https://chatgpt.com/) (do not use an independently redrawn replacement).
2. In this repository, upload that PNG to **`assets/kin-official-logo.png`**.
3. Commit the image. The KIN Streamlit application will automatically show it in the sidebar and masthead instead of the text-logo fallback.
4. Once the file exists, put this image at the top of the project README:

```html
<div align="center">
  <img src="assets/kin-official-logo.png"
       alt="KIN — Kinetic Intelligence Network. Life changes. KIN moves with you."
       width="760">
</div>
```

The reference logo is a PNG with a solid black background, not a transparent-background SVG. Preserve the source exactly for consistent branding. The project is independently developed and is **not an official Oakland University application**.
