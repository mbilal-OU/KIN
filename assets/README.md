# KIN approved logo — asset installation

The owner-approved KIN branding is:

- **Brand:** KIN
- **Expansion:** Kinetic Intelligence Network
- **Tagline:** Life changes. KIN moves with you.
- **Official project artwork:** metallic-gold intertwined symbol + gold `KIN` with dotted `I`, white name and tagline, black background.

The team provided the exact PNG image as `logo.png` in the project conversation.

## Required asset

Upload the owner-provided image to:

`assets/kin-official-logo.png`

The Streamlit application checks this path and uses it automatically in its sidebar and top brand area. If the file is missing it uses a text-brand fallback.

A full-quality downloadable ZIP with both the original image and an icon crop is available in the associated project conversation. This markdown file alone does not constitute an image upload.

## Use

- README: insert `<img src="assets/kin-official-logo.png" alt="KIN — Kinetic Intelligence Network. Life changes. KIN moves with you." width="700">` once the image is actually committed.
- App: `app.py` already detects `assets/kin-official-logo.png`.
- Pitch deck / landing page: reuse the same black-and-gold asset rather than independently redrawing or changing lettering.
- For small icons, use the owner-approved interwoven symbol cropped from the original, not a substitute logo.

The original is raster artwork with a black background. Don't claim an editable vector or transparent-background version exists when it does not. No official OU university marks have been used; the company brand is independent of Oakland University.
