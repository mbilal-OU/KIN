# KIN Brand Assets and Usage

**Project identity:** KIN — **Kinetic Intelligence Network**  
**Tagline:** *Life changes. KIN moves with you.*  
**Consumer message:** *More than a calendar. A calmer way to live.*

## Primary logo draft (v1)
- `../assets/kin-wordmark.svg`: original wordmark for README, website header, slides and demo.
- `../assets/kin-icon.svg`: original symbol for favicon, application icon and avatars.

These editable SVG source assets are **KIN design proposals**, not an Oakland University mark or a registered/exclusive trademark. The project owner can approve them as KIN's primary logo. No use of the Golden Grizzlies official bear mascot, OU seal or interlocking university marks is authorized or implied.

The mark uses a network of joined lines forming a stylized K, referring to the Kinetic Intelligence Network mission: connecting schedules, contextual changes and opportunities.

## Typography and accessibility
- Recommended: Inter or system sans-serif; do not commit proprietary font files.
- Minimum readable mobile body type around 16px where feasible.
- Test WCAG AA contrast independently; gold alone is not a sufficient status cue.
- Respect reduced-motion preference for site animations.
- Give the SVG `alt` text: “KIN — Kinetic Intelligence Network.”
- All alerts must be explicitly labeled LIVE, SIMULATED or UNAVAILABLE in text and not just color.

## Logo placement
- Use the full `kin-wordmark.svg` on light surfaces.
- Use the `kin-icon.svg` for application icons or dark-background cards.
- Avoid stretching, rotating, extraneous gradients or copying OU brand assets.
- Keep generous clear space around the icon.
- Avoid suggesting the stylized K is an official university logo.

## Theme portability
The OU-inspired theme applies to the Oakland University hackathon demo. A future KIN personal/enterprise product can use other approved color themes without changing the underlying brand or the user's independently selected assistant nickname.
